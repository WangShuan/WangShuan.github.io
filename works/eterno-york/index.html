Eterno York

Shopify 前台客製與功能開發・MiniMog

// 專案持續時間 2025.09 ~ 2025.11

接手 Eterno York 未完工的 Shopify 前台專案，
進行架構優化、功能收尾與細節修正。

客製商品尺寸表彈窗（含語系與單位切換）、
處理外掛翻譯問題，並依據非正規設計稿調整前台頁面與 UI 邏輯。

專案期間與海外團隊協作，對齊需求並完成功能整合，
最終順利完成網站收尾並上線。

挑戰與解法

// 每個功能點都是在平台限制下，用客製化方式解決實際業務需求。

01接手未完工專案，優化架構並完成收尾

從中途接手既有程式與頁面，釐清現況後進行結構優化與功能補完，確保網站可正常上線。

02客製商品尺寸表彈窗，整合語系與單位切換

根據品牌已安裝之尺寸表彈窗外掛，協助客製化公分／英寸切換功能，並整合多語系顯示。

03針對外掛進行客製化翻譯處理

於可行性範圍內處理外掛翻譯問題，確保中英文介面用詞一致。

04依據非正規設計稿進行頁面實作與 UI 調整

面對不完整的設計稿，靈活調整前台結構與互動邏輯，還原品牌需求。

05與海外團隊協作，進行需求對齊與功能整合

跨時區溝通需求，確認功能規格並完成前後端相關整合。
