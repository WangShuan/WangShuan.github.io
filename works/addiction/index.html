台灣高絲 ADDICTION

SHOPLINE 前台客製與功能開發・Liquid.js

// 專案持續時間 2021.10 ~ 2026.10

為台灣高絲 ADDICTION 進行高度客製化前台開發，
突破 SHOPLINE 平台預設限制，
完整還原日本官方網站的架構與品牌體驗。

同時配合品牌行銷檔期，長期開發多種特規 NEWS 分頁；
串接 SHOPLINE Open API 實作訂單報表自動上傳功能；
開發獨立後台系統以配合實體門市進行掃碼兌換活動。

專案自 2021 年 10 月啟動，
歷經長期維運、功能持續擴充與編輯器版本遷移，
直至 2026 年 10 月品牌撤櫃後終止網站服務，
完整陪伴品牌電商營運至最後階段。

挑戰與解法

// 每個功能點都是在平台限制下，用客製化方式解決實際業務需求。

01突破平台限制，高度還原日本 ADDICTION 官網架構

透過深度 Liquid.js 客製與樣式覆蓋，讓 SHOPLINE 前台在視覺與資訊架構上盡可能貼近日本官方網站，維持品牌一致性。

02配合品牌行銷檔期，長期客製各種特規 NEWS 分頁

配合商品上市檔期，參考日本官方網站發布之頁面，通過品牌提供之中文內容對照簡報，復刻出中文版的 NEWS 頁面，並保持頁面的可擴充、可維護性。

03串接 Open API 整合訂單資料，實作報表自動上傳功能

透過 SHOPLINE Open API 於每日固定時間抓取訂單資料，並客製化成指定的規格架構後，自動上傳至 Google 雲端硬碟，以供 ERP 廠商獲取，減少人工處理時間與錯誤。

04獨立建置額外後台系統，管理實體門市掃碼兌換活動

額外開發獨立後台，讓門市人員可根據需求建立檔期活動，並使用後台掃碼功能核銷兌換資格；另於 SHOPLINE 建立對應的前台活動兌換頁，將其與客製化後台進行完整串接，供客戶填寫與出示條碼進行兌獎。

05長期合作維運，經歷編輯器版本遷移與持續功能擴充

從專案上線至 2026 年撤櫃為止持續維護，期間完成編輯器大版本遷移，並依品牌需求不斷優化、擴充新功能，完整陪伴品牌電商營運至最後階段。
